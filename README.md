# 📈 家庭基金账目管理系统 (Family Fund Management System)

一个专门为家庭/小型合伙基金设计的 **高精度、可追溯、全自适应** 的资产账目与份额净值管理系统。基于 **事件溯源 (Event Sourcing)** 架构开发，保证账目的历史可追溯性与绝对准确度。

---

## ✨ 核心功能亮点

* **📅 事件溯源重放计算**：采用先进的事件溯源架构，所有的入金、出金、份额转让与估值更新均被记录为独立事件，系统通过历史流重放计算成员的最精细化资产净值与份额。
* **💹 份额净值实时核算**：实时追踪每一笔交易发生瞬间的基金总资产（Total NAV）、总份额（Total Shares）与单位净值（NAV per Share）。
* **🔄 人民币/美元双维度双币核算**：
  * 支持输入实际的人民币流水并记录美元出资；
  * 内置自适应汇率同步接口，启动时静默同步全球最新离岸人民币（CNH）汇率。
* **📉 标普500/纳指100指数对比**：静默后台从 Yahoo Finance 同步对标美股大盘指数（SPX、NDX），并在前端生成归一化走势对比图表，直观了解投资表现是否跑赢大盘。
* **🔁 成员内部份额划转**：支持家庭成员之间的高精度份额转让与资产转拨，自动折算对应时间节点的净值与汇率。
* **🛡️ 极致的安全机制与自动备份**：
  * **数据绝不丢失**：数据存放在本地 `data/db.json` 文件中，每次写入账目都会在 `backups/` 目录下自动生成一个时间戳备份文件（滚动留存最新的 15 个备份，防止磁盘爆满）。
  * **删除安全保护**：已产生财务流水（如出入金）的成员，系统将绝对禁止直接删除其账号，防止破坏历史财务计算链条。
  * **一键导出导入**：支持一键导出整套账目，并支持在任意新设备上一键导入重算。

## 🚀 快速启动指南

为了方便家庭成员使用，项目已内置 **一键免命令启动器**：

### 💻 方案 A：双击一键启动（推荐）

* **Windows 用户**：
  直接双击项目根目录下的 **`start.bat`** 脚本即可。
* **macOS 用户**：
  首次使用时需要授权，请打开终端，输入 `chmod +x `（+x 后面有一个空格），把 **`start.command`** 文件拖入终端回车。之后只需双击 `start.command` 即可运行。

> **启动器会自动为您完成以下配置：**
> 1. 自动检查是否安装了 Node.js（若无则提示下载）。
> 2. 自动检查并安装依赖环境。
> 3. 自动在浏览器中为您打开系统主界面：👉 **[http://localhost:3000](http://localhost:3000)**

---

### 🛠️ 方案 B：手动命令启动

如果您习惯使用命令行，也可以通过以下步骤手动启动：

1. **安装环境**：请确保电脑已安装 [Node.js](https://nodejs.org/)。
2. **安装依赖**（仅需首次执行）：
   ```bash
   npm install
   ```
3. **启动服务器**：
   ```bash
   npm start
   ```
4. **浏览器访问**：打开浏览器，访问 `http://localhost:3000`。

* **方法一**：直接点击关闭弹出的命令行/终端窗口，服务即刻安全停止。

## ⚙️ 进阶配置与常见问题 (FAQ)

### 1. 端口冲突/自定义运行端口
系统默认运行在 `3000` 端口。如果您的电脑上该端口已被其他程序占用，或者您希望自定义端口，可以通过以下方式指定：
* **命令行/终端启动**：
  * **macOS/Linux**：
    ```bash
    PORT=3001 npm start
    ```
  * **Windows (PowerShell)**：
    ```powershell
    $env:PORT=3001; npm start
    ```
  * **Windows (CMD)**：
    ```cmd
    set PORT=3001 && npm start
    ```
* **一键启动器修改**：您也可以直接右键编辑 `start.bat` 或 `start.command`，在 `npm start` 前加入对应的端口声明。

### 2. 美股大盘指数（SP500/纳指100）对比图未显示？
* **原因**：系统内置后台静默同步机制，请求 Yahoo Finance 获取指数收盘价。在部分国内网络环境下，可能会因为网络限制导致 API 请求超时或失败。
* **影响**：此问题**完全不会**影响成员资金录入、出入金以及高精度的份额计算，仅影响大盘对比走势图的渲染。
* **解决建议**：可开启网络代理，或在连网状态下重新启动服务，系统成功拉取并缓存数据后，后续即使离线也能正常展示历史图表。

### 3. 数据备份与恢复如何操作？
* **自动备份**：系统在每次执行入金、出金等写操作时，都会在 `backups/` 下自动生成一个带时间戳的 `db_xxxx.json` 备份（自动滚动留存最新的 15 个，无需手动维护，安全防丢）。
* **手动备份/迁移**：
  * 可以在系统主页点击 **“导出数据”** 按钮，一键下载完整的账目备份文件。
  * 在新设备或重设系统时，点击 **“导入数据”** 并选择该备份文件，系统将一键载入并自动重算所有历史份额净值。
  * 您也可以直接手动备份或拷贝项目根目录下的 `data/db.json` 文件。

## 🛠️ 技术底座与依赖

* **后端框架**：Node.js + Express
* **数据存储**：本地轻量化 JSON File Database (自制高内聚数据同步存取器)
* **网络请求**：原生 HTTPS + UA 欺骗 (用于 Yahoo Finance 接口获取指数历史收盘价)
* **外部 API 接口**：
  * ExchangeRate-API (免 Key 极速汇率同步接口)
  * Yahoo Finance API (`query2.finance.yahoo.com` 数据线)
